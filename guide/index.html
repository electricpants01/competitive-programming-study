Introduction

Competitive programming (CP) is the practice of solving well-defined algorithmic problems within strict time and memory limits. Mastering CP requires a deep understanding of algorithms, data structures, and mathematical reasoning.

This guide covers the essential topics you need to go from beginner to competitive in platforms like Codeforces, LeetCode, AtCoder, and ICPC.

Each topic includes a clear description, complexity analysis, C++ implementations, best practices, and curated practice problems.

A phased plan to go from beginner to competitive programmer.

Foundations

2
Core Algorithms
Weeks 5–10 · Codeforces Div. 3 / LeetCode Medium
Two Pointers
Sliding Window

BFS / DFS
Union-Find (DSU)
Greedy Techniques
3
Dynamic Programming
Weeks 11–16 · Codeforces Div. 2 / LeetCode Hard
1D DP (Coin Change, LIS)
2D DP (LCS, Grid DP)
Knapsack Variants
Interval DP
Bitmask DP
DP on Trees
4
Graph Theory
Weeks 17–22 · Codeforces Div. 2–1
Dijkstra's Algorithm
Bellman-Ford / SPFA
Floyd-Warshall
Minimum Spanning Tree
Topological Sort
Strongly Connected Components
5
Advanced Data Structures & Math
Weeks 23+ · Codeforces Div. 1 / ICPC level
Segment Tree + Lazy Prop
Fenwick Tree (BIT)
Trie
Modular Arithmetic
Combinatorics
