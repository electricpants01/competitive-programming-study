# Skill: Video Library Feature

How the CP Video Library works — architecture, data format, scraper, i18n, and gotchas.

---

## Overview

The Video Library lets users browse and search CP tutorial videos from curated Spanish/English
YouTube channels. Videos are filterable by channel, topic tag, and keyword. When transcripts are
available, keyword search highlights matching segments with deep-link timestamps.

## Data Files

Both files are auto-generated by `scripts/scrape-videos.cjs`. **Never edit manually.**

### Regenerating

```bash
# Spanish channels (primary)
node scripts/scrape-videos.cjs

# English channels
node scripts/scrape-videos.cjs en
```

Files written to `public/videos-data-es.js` and `public/videos-data-en.js`.

### Data Shape

```js
const videosData = {
  channels: [
    { id: string, name: string, url: string }
  ],
  videos: [
    {
      id: string,           // YouTube video ID
      title: string,        // Video title
      channel: string,      // Channel ID (matches channels[].id)
      channelName: string,  // Channel display name
      thumbnail: string,    // YouTube thumbnail URL (hqdefault)
      duration: string,     // Formatted e.g. "42:07"
      durationSecs: number, // Total seconds
      tags: string[],       // Topic tags derived from keyword map
      segments: [           // Transcript segments (may be empty on 429)
        {
          t: number,        // Start time in seconds
          text: string,     // Segment text
          tags: string[],   // Tags from this segment's keywords
        }
      ],
    }
  ]
};
```

### Channel Registry (`scripts/video-channels.cjs`)

Exports `CHANNELS` array and `KEYWORD_MAP`. Add a new channel by pushing to `CHANNELS`:

```js
{
  id: 'unique-id',          // used as channel field on videos
  name: 'Display Name',
  url: 'https://www.youtube.com/@handle',
  lang: 'es',               // 'es' or 'en'
  playlistEnd: 20,          // max videos to fetch
}
```

`KEYWORD_MAP` is a flat object mapping lowercase keyword → topic tag array. Used to auto-tag
video titles and transcript segments.

## `initVideoSearch()` Runtime Logic

Called at page load. Reads `window.videosData` (populated by the data file).

### Graceful Degradation

If `videosData` is undefined (file missing or load error), shows `t.videos.noResults` and returns.
This prevents JS errors when the data file hasn't been generated yet.

### Filter Logic

1. **Channel filter** — built from `data.channels` at runtime; "All Channels" = `''`
2. **Tag filter** — union of all `v.tags` arrays across all videos; OR mode (any match)
3. **Keyword search** — matches `v.title.toLowerCase()` OR any `seg.text.toLowerCase()`

### Transcript Segments

When a keyword matches, up to 5 matching segments are shown per card as deep-link chips:
`https://www.youtube.com/watch?v={id}&t={seg.t}s`

## Known Gotchas

1. **YouTube 429 on subtitle download**: The VTT subtitle API rate-limits aggressively. If the
   scraper is run too frequently, all subtitle requests fail with HTTP 429. The data files are
   still written with all video metadata; only `segments` will be empty arrays.
   **Workaround**: Run the scraper once per session, or add delays between requests in
   `scrape-videos.cjs`.

2. **Data files loaded at runtime**: `videos-data-{lang}.js` is loaded with `is:inline src`,
   meaning it's a runtime fetch from `public/`. The build does **not** fail if the file is absent,
   but the browser will log a 404 and `initVideoSearch()` will show the no-results message.

3. **Both EN and ES data files must exist**: The page loads `videos-data-${lang}.js` based on the
   current locale. Create both by running the scraper for each locale.

4. **Tag cloud built at runtime**: Topic tags are derived from `v.tags` across all videos. If no
   videos have tags (e.g. scraper ran with all 429s), the tag cloud will be empty.

5. **Section uses `<style is:global>`**: The `.vl-*` classes must be global because `.vl-channel-btn`
   and `.vl-card` elements are injected by JS at runtime and won't receive Astro's scoped attribute.
