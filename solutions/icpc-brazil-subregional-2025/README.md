# Maratona SBC / LatAm Sub-Regional 2025 — C++ Solutions

These C++17 implementations correspond to Problems A–M in the English problem booklet
(`2025-brazil-subregional-en.pdf`). The same contest was used for Gran Premio de
Centroamérica / México and Competencia Boliviana.

They are intentionally separate from the browser editorial. The editorial exposes only:

- estimated difficulty order;
- ASCII visualization;
- key insight and solution analysis;
- complexity.
