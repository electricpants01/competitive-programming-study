# ACM ICPC Preliminaries — Feature Spec

## Summary

Guide section that lists curated **ICPC preliminary / qualifier / sub-regional** problem-set PDFs for offline practice. Files are vendored under `public/icpc-prelims/` and linked with `BASE_URL`.

## Goals

- Sidebar entry under PRACTICE: `icpc-prelims`
- Browse contests by region and kind
- Open / download local PDFs (no scrape at runtime)
- Read visual, difficulty-sorted editorials when available
- EN / ES i18n for UI chrome

## Non-goals

- Hosting judge test data or interactive submission
- Auto-updating PDFs from the network
- Full World Finals archive (see icpcarchive for that)
