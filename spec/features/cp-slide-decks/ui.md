# CP Slide Decks — UI / HTML Spec

## Viewport

`1920px × 1080px`, `overflow: hidden`, dark slate background.

## Naming

`NN-subtopic-N.html` e.g. `03-gcd-lcm-2.html`.

## Header

- Topic label + "Diapositiva N de M" (or EN equivalent if used)
- Title
- Global `slide-num` badge

## Slide types per subtopic

1. Definition / motivation  
2. Algorithm / trace  
3. Application (optional)  
4. C++ code + annotations + complexity  

## Code blocks

macOS-style window chrome; span classes `.kw .fn .tp .cm .nu .str`.

## Palettes

Per subtopic type (primality blue, factorization purple, GCD emerald, …) — see skill doc.
