# Algorithms Content — Feature Spec

## Summary

Structured topic content powering guide detail panels: descriptions, ASCII diagrams, C++ examples, quizzes, and practice links — maintained as dual EN/ES plain JS files.

Canonical skill: `AI/skills/algorithms-data.md`. Schema: [07-content-schema.md](../../07-content-schema.md).

## Goals

- Stable topic IDs across locales
- ≥2 code examples and ≥5 quiz questions per topic
- Sidebar coverage with no orphans

## Non-goals

- In-browser topic editor
- Auto-translation
