# 04 — Data Contracts

This project has no first-party REST API. Contracts cover static globals, external HTTP, and browser storage.

---

## 1. Algorithms data (`window.algorithmsData`)

Loaded from `public/algorithms-data-{lang}.js`.

```js
const algorithmsData = {
  "topic-id": {
    title: string,
    category: string,
    difficulty: string,
    timeToLearn: string,
    importance: string,          // "Essential" | "High" | "Intermediate"
    description: string,
    asciiArt: string,
    keyTechniques: string[],
    benefits: string[],
    typicalConstraints: string[],
    examples: [{ title, description, codeSnippet }],
    bestPractices: string[],
    problems: string[],
    quiz: [{ q, options: string[4], answer: number /* 0-index */ }],
  },
};

const sidebarSections = [
  { label: "SECTION LABEL", items: [{ id: "topic-id", title: "Display Title" }] },
];
```

Rules: every topic ID appears in exactly one sidebar section; IDs are stable across EN/ES. Full rules: [07-content-schema.md](./07-content-schema.md).

## 2. Videos data (`window.videosData`)

Generated by `scripts/scrape-videos.cjs`. **Do not edit by hand.**

```js
const videosData = {
  channels: [{ id, name, url }],
  videos: [{
    id, title, channel, channelName, thumbnail,
    duration, durationSecs, tags: string[],
    segments: [{ t: number, text: string, tags: string[] }],
  }],
};
```

Empty `segments` is valid (YouTube 429 during scrape).

## 5. Codeforces API (runtime)

```
GET https://codeforces.com/api/problemset.problems
```

Response (relevant fields):

```json
{
  "status": "OK",
  "result": {
    "problems": [
      {
        "contestId": 1234,
        "index": "A",
        "name": "Problem Name",
        "rating": 1200,
        "tags": ["dp", "greedy"]
      }
    ]
  }
}
```

Client keeps only problems **with** a `rating`. No auth. CORS works from browsers; on failure show `t.search.errorMsg`.

Problem key format: `` `${contestId}-${index}` ``.

## 7. Client translation bridge

```js
window.__CP_LANG__ = 'en' | 'es';
window.__CP_T__ = /* parsed Translations object */;
```

Injected from Astro via `define:vars` + `JSON.stringify` / `JSON.parse`.

**Important:** `JSON.stringify` cannot serialize functions. Interpolated strings use **templates** with `{placeholders}`:

| Key | Template example |
|-----|------------------|
| `sidebar.progress` | `{pct}% Complete` |
| `search.problemsFound` | `{n} problems found` |
| `search.pageOf` | `Page {page} of {total}` |
| `videos.watchAt` | `▶ Watch at {ts}` |
| `videos.matchesFound` | `{n} transcript matches` |
| `quiz.score` | `You got {correct} out of {total} correct!` |

Client scripts format these with a small `fmt(template, vars)` helper.

Also: `search.retryBtn` labels the Retry control shown with `errorMsg`.

---

## Error envelope (external)

- CF API / network errors → UI status bar (no structured error JSON of our own).
- Missing `videosData` → graceful empty state (`t.videos.noResults`), no throw.
