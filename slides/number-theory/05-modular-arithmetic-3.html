Exponenciación Rápida (Fast Power)
18 / 26

🤔 El problema

Calcular aⁿ mod m multiplicando n veces es O(n). Para n = 10¹⁸ es imposible. Necesitamos algo mejor.

💡 La idea: dividir el exponente a la mitad

aⁿ = (a^(n/2))² si n es par
aⁿ = a · (a^((n−1)/2))² si n es impar

En lugar de n multiplicaciones, solo necesitamos log₂(n) pasos.

📊 Traza: 2¹⁰ mod 1000

pow(2,10)
→ par
= (2⁵)² = 32² mod 1000 = 1024 mod 1000 = 24
pow(2,5)
→ impar
= 2 · (2²)² = 2 · 4² = 2 · 16 = 32
pow(2,2)
→ par
= (2¹)² = 1² · 2 = 4
pow(2,1)
→ base
= 2
✓ Solo 4 pasos en lugar de 10
❌ Método lento O(n)
2¹⁰⁰⁰ = 2×2×2×...×2
1000 multiplicaciones
Para n = 10¹⁸ → imposible
✅ Rápido O(log n)
2¹⁰⁰⁰ → ~10 pasos
2^(10¹⁸) → ~60 pasos
¡Siempre manejable!

💻 Implementación iterativa

long long powmod(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp % 2 == 1)          // si exp es impar
            result = result * base % mod;
        base = base * base % mod;   // elevar al cuadrado
        exp /= 2;                  // dividir exp a la mitad
    }
    return result;
}
Complejidad: O(log n)
¡De O(10¹⁸) a solo O(60) pasos!
