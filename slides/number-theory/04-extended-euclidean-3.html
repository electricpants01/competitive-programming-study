🔐 ¿Qué es el Inverso Modular?

El inverso modular de a módulo m es un número x tal que:

a · x ≡ 1 (mod m)

Es el equivalente de 1/a en aritmética modular. Existe solo si mcd(a,m) = 1.

🧮 Ejemplo: inverso de 3 módulo 7

Queremos x tal que 3·x ≡ 1 (mod 7)

3·1=3
3·2=6
3·5=15≡1
3·4=12≡5
3·3=9≡2
3·6=18≡4
✓ El inverso modular de 3 (mod 7) es 5
Verificar: 3 × 5 = 15 = 2×7 + 1 ≡ 1 (mod 7) ✓

⚙️ Cómo calcularlo con Euclides Extendido

Paso 1: Plantear la ecuación
Queremos: a·x + m·y = 1
Si mcd(a,m)=1, esta ecuación tiene solución
Paso 2: Aplicar mcd_extendido(a, m)
Obtenemos x e y tal que a·x + m·y = mcd(a,m) = 1
Paso 3: El coeficiente x es el inverso
Como a·x ≡ 1 (mod m), entonces x es la respuesta
Paso 4: Normalizar si es negativo
Si x < 0: x = (x % m + m) % m
Asegura que el resultado esté en [0, m-1]
inv(3, 7) = 5

Euclides extendido: 3·5 + 7·(−2) = 15 − 14 = 1

x = 5 → inverso de 3 módulo 7

🚀 ¿Para qué se usa en CP?
Dividir módulo primo: en vez de (a/b) % MOD, calcular a · inv(b, MOD) % MOD
