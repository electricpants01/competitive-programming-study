¿Qué es una Ecuación Diofántica Lineal?
23 / 26

📖 Definición

ax + by = c

Una ecuación donde a, b, c son enteros fijos y buscamos soluciones enteras para x e y. Se llama "diofántica" en honor al matemático griego Diofanto de Alejandría (~250 d.C.).

🔑 ¿Cuándo tiene solución?

Teorema de Bezout aplicado
Tiene solución si y solo si mcd(a, b) divide a c
Es decir: c mod mcd(a,b) = 0
¿Cuántas soluciones?
Si tiene una solución, tiene infinitas.
Si (x₀, y₀) es solución, entonces también lo son:
x = x₀ + (b/d)·t,   y = y₀ − (a/d)·t
para todo entero t, donde d = mcd(a,b)
Ejemplos
3x + 5y = 7
mcd(3,5) = 1
1 | 7 → ✅ Tiene solución
6x + 9y = 15
mcd(6,9) = 3
3 | 15 → ✅ Tiene solución
6x + 9y = 7
mcd(6,9) = 3
3 ∤ 7 → ❌ Sin solución
2x + 4y = 6
mcd(2,4) = 2
2 | 6 → ✅ Tiene solución

📐 Diferencia con ecuaciones reales

En los reales, 3x + 5y = 7 tiene infinitas soluciones (una línea). En los enteros, solo buscamos los puntos de esa línea con coordenadas enteras. ¡Son mucho más escasos!

Condición necesaria y suficiente:
mcd(a, b) | c
