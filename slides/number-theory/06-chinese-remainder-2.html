📐 Fórmula general

Para el sistema x ≡ aᵢ (mod mᵢ) con módulos coprimos:

M = m₁ × m₂ × ... × mₖ
Mᵢ = M / mᵢ
yᵢ = Mᵢ⁻¹ (mod mᵢ)
x = (Σ aᵢ · Mᵢ · yᵢ) mod M

🔢 Aplicando al ejemplo: x≡2(mod3), x≡3(mod5), x≡2(mod7)

Paso 1: M = 3 × 5 × 7
M = 105
Paso 2: Calcular Mᵢ = M / mᵢ
M₁ = 35, M₂ = 21, M₃ = 15
Paso 3: Calcular yᵢ = Mᵢ⁻¹ (mod mᵢ)
y₁ = 35⁻¹ mod 3 = 2 (35×2=70≡1 mod3 ✓)
y₂ = 21⁻¹ mod 5 = 1 (21×1=21≡1 mod5 ✓)
y₃ = 15⁻¹ mod 7 = 1 (15×1=15≡1 mod7 ✓)
Paso 4: x = (a₁M₁y₁ + a₂M₂y₂ + a₃M₃y₃) mod M
x = (2·35·2 + 3·21·1 + 2·15·1) mod 105
x = (140 + 63 + 30) mod 105
x = 233 mod 105 = 23 ✅
