isPrime.cpp 
#include <iostream>
#include <cmath>
using namespace std;

// Retorna true si n es primo, false si no lo es
bool esPrimo(long long n) {
    if (n <= 1) return false; // 0 y 1 no son primos
    if (n <= 3) return true;  // 2 y 3 son primos
    if (n % 2 == 0) return false; // pares no son primos

    // Solo revisamos impares hasta √n
    for (long long i = 3; i * i <= n; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    long long n;
    cin >> n;
    cout << (esPrimo(n) ? "ES PRIMO" : "NO es primo") << endl;
    return 0;
}
🛡️
Casos base: Manejamos n ≤ 3 y pares al inicio para evitar errores y mejorar velocidad.
⚡
i * i <= n es equivalente a i <= √n pero evita usar la función sqrt() (más rápido y exacto).
➕
i += 2 salta los pares. Como ya descartamos el 2, solo necesitamos revisar impares.

📋 Ejemplos de salida

esPrimo(2) true ✓
esPrimo(17) true ✓
esPrimo(100) false ✗
esPrimo(999983) true ✓
esPrimo(1) false ✗

💡 Trucos para recordar

▸Todo primo > 2 es impar
▸El 2 es el único primo par
▸El 1 NO es primo por definición
▸Complejidad: O(√n) por número
