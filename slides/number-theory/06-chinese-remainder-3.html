🌟 ¿Para qué sirve?

El TCR tiene aplicaciones tanto en matemáticas puras como en problemas reales de computación.

🚀 Aplicaciones principales

🔐 Criptografía RSA
Se usa para acelerar el descifrado RSA. En vez de trabajar con números enormes, se trabaja con números más pequeños módulo p y q (los factores primos de n).
💻 Aritmética de precisión arbitraria
Para multiplicar números muy grandes, se usa el TCR para dividir el problema en varios módulos pequeños y luego reconstruir el resultado.
🏆 Competitive Programming
Problemas de tipo "encuentra x tal que x mod mᵢ = aᵢ" aparecen frecuentemente. El TCR da la solución directa en O(n log m).

⚠️ Cuando los módulos NO son coprimos

Si mcd(mᵢ, mⱼ) ≠ 1 para algún par, el sistema puede:

▸ No tener solución (inconsistente)
▸ Tener infinitas soluciones
▸ Requerir el TCR generalizado

En CP, generalmente los módulos dados son coprimos entre sí — verificar siempre.
