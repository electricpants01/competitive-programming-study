⚙️ Idea del algoritmo

Hacemos la misma división que el Euclides normal, pero rastreamos hacia atrás los coeficientes x e y usando las relaciones de recurrencia:

📐 Relaciones de recurrencia

x₀ = 1, x₁ = 0
Valores iniciales para x
y₀ = 0, y₁ = 1
Valores iniciales para y
xᵢ = xᵢ₋₂ − q · xᵢ₋₁
Actualizar x usando el cociente q = a ÷ b
yᵢ = yᵢ₋₂ − q · yᵢ₋₁
Actualizar y usando el cociente q
En cada paso se cumple: a·xᵢ + b·yᵢ = rᵢ
donde rᵢ es el residuo en ese paso
