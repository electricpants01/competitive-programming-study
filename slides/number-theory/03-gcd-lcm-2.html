🔑 La idea de Euclides (300 a.C.)

Si a = b × q + r (a dividido entre b da residuo r), entonces:
MCD(a, b) = MCD(b, r)
¡Podemos reemplazar el problema con uno más pequeño!

mcd(a, b) = mcd(b, a mod b)

Repetir hasta que b = 0. Cuando b = 0, la respuesta es a.

Pasos del algoritmo

1
Si b = 0, el MCD es a. ¡Terminar!
2
Calcular el residuo: r = a mod b
3
Reemplazar: a ← b, b ← r
4
Volver al paso 1

📊 Traza: MCD(252, 198)

aba mod bNuevo (a, b)
252 198 252 mod 198 = 54 (198, 54)
198 54 198 mod 54 = 36 (54, 36)
54 36 54 mod 36 = 18 (36, 18)
36 18 36 mod 18 = 0 (18, 0)
✅ b = 0 → MCD(252, 198) = 18
