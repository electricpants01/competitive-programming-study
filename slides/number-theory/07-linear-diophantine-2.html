Cómo Encontrar Una Solución
24 / 26

💡 El método

Usar el Algoritmo de Euclides Extendido para encontrar x₀, y₀ tal que ax₀ + by₀ = mcd(a,b), luego escalar para que el resultado sea c.

⚙️ Pasos para resolver ax + by = c

Paso 1: Verificar condición
Calcular d = mcd(a, b). Si d no divide a c → sin solución.
Paso 2: Resolver ax + by = d
Usar mcd_extendido(a, b, x₀, y₀) que da ax₀ + by₀ = d
Paso 3: Escalar por c/d
Multiplicar ambos lados: a(x₀·c/d) + b(y₀·c/d) = c
Solución particular: x = x₀·(c/d), y = y₀·(c/d)
Paso 4: Familia de soluciones
x(t) = x₀·(c/d) + (b/d)·t
y(t) = y₀·(c/d) − (a/d)·t
para cualquier entero t

🔢 Ejemplo completo: 6x + 9y = 12

Paso 1: d = mcd(6, 9) = 3. ¿3 | 12? Sí ✓
La ecuación tiene solución
Paso 2: mcd_ext(6, 9) → 6·(−1) + 9·1 = 3
x₀ = −1, y₀ = 1 (solución para el MCD)
Paso 3: Escalar por c/d = 12/3 = 4
x = −1 × 4 = −4, y = 1 × 4 = 4
Solución particular: x = −4, y = 4
Verificar: 6×(−4) + 9×4 = −24 + 36 = 12 ✓
Paso 4: Familia completa de soluciones (d=3)
x(t) = −4 + 3t
y(t) = 4 − 2t

📊 Primeras soluciones (t = 0, 1, 2, −1)

t=0: x=−4, y=4 → 6(−4)+9(4)=12 ✓
t=1: x=−1, y=2 → 6(−1)+9(2)=12 ✓
t=2: x=2, y=0  → 6(2)+9(0)=12 ✓
t=−1: x=−7, y=6 → 6(−7)+9(6)=12 ✓
