🏛️ Pequeño Teorema de Fermat

Si p es primo y a no es múltiplo de p:

aᵖ⁻¹ ≡ 1 (mod p)

Por tanto: a⁻¹ ≡ aᵖ⁻² (mod p)

¡Podemos calcular el inverso modular usando potenciación rápida!

modular.cpp 
const long long MOD = 1e9 + 7;

long long powmod(long long b, long long e, long long m) {
    long long r = 1; b %= m;
    while (e > 0) {
        if (e & 1) r = r * b % m; // bit menos significativo
        b = b * b % m;
        e >>= 1;               // desplazar bits a la derecha
    }
    return r;
}

// Inverso por Fermat (solo para p primo)
long long inv(long long a) {
    return powmod(a, MOD - 2, MOD);
}

int main() {
    long long a = 2, b = 3;
    cout << (a + b) % MOD << endl;        // suma mod
    cout << a * inv(b) % MOD << endl;    // división mod
    cout << powmod(2, 1000000000, MOD); // 2^10⁹ mod p
}
e & 1: comprueba si el bit menos significativo es 1 (si e es impar). Más rápido que e % 2.
e >>= 1: divide entre 2 usando bits. Equivalente a e /= 2 pero más eficiente.
inv(a) = a^(MOD-2) % MOD: funciona porque MOD = 10⁹+7 es primo → Fermat aplica.
$ ./modular

📌 Plantilla mínima para CP
▸ Suma: (a+b)%MOD
▸ Resta: (a-b+MOD)%MOD
▸ Mult: a*b%MOD
▸ Div: a*inv(b)%MOD
▸ Pot: powmod(a,b,MOD)
