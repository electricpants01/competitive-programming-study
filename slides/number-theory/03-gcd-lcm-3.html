MCM: Mínimo Común Múltiplo
10 / 26

📖 Definición

El Mínimo Común Múltiplo (MCM) de a y b es el número más pequeño que es múltiplo de ambos a la vez.

✓ MCM(4, 6) = 24 (el primer múltiplo en común)

🔗 Relación Clave: MCD × MCM = a × b

mcm(a, b) = (a × b) / mcd(a, b)

¡Usamos el MCD que ya sabemos calcular para obtener el MCM!

🚀 Aplicaciones

▸Sumar fracciones: necesitamos el denominador común
▸Problemas de sincronización (ciclos, relojes)
▸Teoría de números en competencias
Ejemplos prácticos
a = 12, b = 18
MCD(12,18) = 6
MCM = (12×18)/6 = 36
12→12,24,36 | 18→18,36 ✓
a = 8, b = 12
MCD(8,12) = 4
MCM = (8×12)/4 = 24
8→8,16,24 | 12→12,24 ✓
a = 5, b = 7
MCD(5,7) = 1 (coprimos)
MCM = (5×7)/1 = 35
Cuando MCD=1, MCM=a×b
a = 6, b = 9
MCD(6,9) = 3
MCM = (6×9)/3 = 18
6→6,12,18 | 9→9,18 ✓
⚠️ Cuidado con el Overflow
Al calcular a * b puede desbordar un int.
✓ Solución: calcular a / mcd(a,b) * b
Divide primero, luego multiplica — evita el overflow.
