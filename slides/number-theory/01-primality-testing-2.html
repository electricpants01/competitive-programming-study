Método Básico: Dividir por Todos
02 / 26

💡 La idea

Para saber si n es primo, intentamos dividirlo por todos los números desde 2 hasta n−1. Si alguno divide exactamente → no es primo. Si ninguno divide → ¡es primo!

Pasos del algoritmo
1
Si n ≤ 1, NO es primo (caso especial).
2
Para cada i desde 2 hasta n−1, pregunta: ¿n ÷ i tiene residuo 0?
3
Si algún n % i == 0 → n NO es primo. ¡Para!
4
Si llegaste al final sin encontrar divisor → n SÍ es primo. ✓
⏱️

Complejidad temporal

O(n)

— Por cada número revisamos hasta n−1 divisores
